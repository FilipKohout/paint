# Paint

Módy
* Line - kreslení úseček, možnost přichycení osy přes Shift
* Square - kreslení čtverců
* Rectangle - kreslení obdélníků
* Polygon - mnohoúhelníky, zrušení posledního bodu klávesou Escape
* Circle - kreslení kružnic
* Fill - nástroj plechovka pro výplň barvou
* Erase - guma s nastavitelnou tloušťkou
* Select Object - výběr a přesun celých objektů, odstranění klávesou Delete
* Select Node - úprava jednotlivých bodů tvarů

Limitace
* Chybí správné vrstvení objektů, objekty se překrývají v pořadí, v jakém byly vytvořeny
* Překreslování se děje při určitých událostech, takže někdy není vidět, co se děje
* Gumování se někdy seká
